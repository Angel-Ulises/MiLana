# MiLana: estrategia de negocio y especificación para ejecutar

**Estado: investigación terminada; implementación pendiente.** Corte de investigación: 14 de septiembre de 2026. Base auditada: commit 64cdc90b783857cc46b2909d22974a433ae7fc05 de Angel-Ulises/MiLana. Sitio observado: https://www.milanaaqui.mx/.

La decisión propuesta es convertir MiLana en una herramienta de referencia para entender el sueldo y las prestaciones en México, y acompañar las decisiones posteriores con comparaciones útiles y monetización transparente. Se conserva el acceso gratuito a las calculadoras y la identidad visual marfil/navy. La ejecución se hará por entregas pequeñas desde GitHub, con vistas previas revisables desde el teléfono.

## Decisiones fijadas para evitar reinterpretar el proyecto

- Prioridad inicial: sueldo neto, aguinaldo y cierre de relación laboral. La rama RESICO se conserva y se monetiza cuando esté revisada y tenga contenido específico.
- Comparar productos por utilidad para el lector. La existencia de comisión no altera el orden editorial ni permite omitir alternativas sin afiliación.
- Primeras conversaciones comerciales propuestas: Klar y docDigitales. Ningún contrato, alta ni comisión individual está confirmado para MiLana.
- Revisar el plan real de hosting antes de monetizar. Si sigue en Vercel Hobby, preparar una vista previa en Cloudflare Pages y una migración controlada con el mismo dominio.
- Publicar inicialmente una pieza original quincenal con ejemplos verificables; reutilizarla en dos piezas breves. No iniciar una redacción diaria ni muchas redes al mismo tiempo.
- Mantener fotografía existente aprovechable, tipografía editorial y colores aprobados. El movimiento debe ayudar a orientarse y respetar la preferencia de reducirlo.
- Los cálculos y los resultados siguen siendo gratuitos. No se establece un muro de pago, un formulario de crédito ni una operación de intermediación financiera.

## Cómo continuar con menos trabajo manual

Al retomar, leer este archivo y solo la tarea elegida, sus fuentes y los archivos implicados. El agente obtiene el estado actual de GitHub, compara los cambios posteriores al commit auditado y ejecuta una tarea acotada. Devuelve enlace a la vista previa, cambios, evidencia de comprobación y solicitud de publicación únicamente cuando corresponda. El usuario no debe descargar parches, abrir Termius ni copiar salidas de terminal.

Esta documentación no autoriza por sí sola publicar la web, aceptar contratos, enviar solicitudes, comprar servicios o escribir a terceros. Esas acciones se resolverán al ejecutar el encargo correspondiente. No es necesario pedir al usuario autorización otra vez para lecturas, preparación o comprobaciones ya incluidas en su encargo.

La investigación sustenta las decisiones; no demuestra que MiLana ya tenga demanda comercial, tráfico suficiente o ingresos futuros. Las variables todavía desconocidas y los experimentos que deben resolverlas están identificados expresamente.
