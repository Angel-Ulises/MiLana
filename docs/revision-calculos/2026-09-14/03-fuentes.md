## Qué no se cerró por un fragmento de buscador

- Los resultados sobre tesis SCJN 250188 y 167048 no permitieron abrir el texto íntegro. No se usan para certificar una fórmula de indemnización; la distinción de escenarios se apoya en la LFT leída. La fracción exacta de antigüedad debe cerrarse con el contexto jurídico aplicable.
- La consulta a datos.imss.gob.mx devolvió 503. El fragmento sobre tope de 25 UMA no se trata como documento íntegro de aplicación operativa. El art. 28 basta para identificar que el código carece de límite, no para declarar terminada la simulación de nómina.
- El primer enlace ensayado al boletín UMA no respondió; se sustituyó por la publicación íntegra de INEGI S3.
- No se utilizó una página comercial de calculadoras como autoridad para corregir el sitio. Que dos calculadoras arrojen lo mismo no prueba conformidad.
